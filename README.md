기존 구글 코랩에서 생성 후 GitHub Pages에 올렸던 과정을 통합한 리포지터리입니다. 

[사용방법]
1. 'data' 파일에 분석할 엑셀을 업로드합니다.
2. 상단 메뉴 'Actions'에서 Analyze Excel을 클릭합니다.
3. 'Run workflow'에서 저장소 안 Excel 파일 경로를 작성하고 실행합니다.
4. 완료된 이후 페이지에 들어가 GitHub Pages 링크를 확인합니다.

하나의 저장소에서 여러 GitHub Pages를 만들 수 있도록 수정하였으며, 분석할 때마다 서로 다른 새로운 링크가 생성됩니다.
